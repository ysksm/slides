やってみよう

コードの読み方

Tutorial 1 · Getting started (2/2)

外部パッケージを呼ぶ：go mod tidy と go.sum

やってみよう

  1. pkg.go.dev でパッケージを探す。ここでは rsc.io/quote の Go() 関数を使う。
  2. hello.go に import "rsc.io/quote" を追加し、quote.Go() を出力する。
  3. go mod tidy で依存を解決し、go.mod と go.sum を更新。
  4. go run .。

ここで起きていること

  • go mod tidy：import 文から必要なモジュールを探し、モジュールプロキシ（proxy.golang.org）から取得して go.mod の require に記録する。
  • go.sum：取得したモジュールのチェックサム。改ざん・差し替えを検出する。両方ともコミットする。
  • // indirect は直接 import していない推移的依存。
  • 取得物は GOMODCACHE に置かれ、他プロジェクトと共有される。

Tutorial 2 · Part 1/7

greetings モジュールを作る

やってみよう

  1. ホームに greetings ディレクトリを作り、go mod init example.com/greetings。
  2. greetings.go に右のコードを書く。まだ実行はしない（main が無いので実行できない）。

モジュールパスは公開するなら実際のリポジトリの場所（github.com/you/greetings など）にする。今回は例なので example.com/。

コードの読み方

  • package greetings：関連する関数をまとめる単位。ディレクトリ 1 つ＝パッケージ 1 つ。
  • 大文字で始まる名前は公開（exported）：Hello は他パッケージから呼べる。小文字なら非公開。
  • func Hello(name string) string：引数 name（string 型）を取り、string を返す。型は名前の後ろに書く。
  • :=：宣言と初期化を同時に行い、型は右辺から推論。var message string = … の短縮形。
  • fmt.Sprintf：%v に値を埋め込んだ文字列を返す（Printf は表示、Sprintf は文字列を返す）。

Welcome!", name) return message } ディレクトリ構成（この後 hello/ を隣に作る）<home>/ ├── greetings/ │ ├── go.mod │ └── greetings.go └── hello/ ← 次のパートで作る

Tutorial 2 · Part 2/7

別モジュールから呼び出す：go mod edit -replace

やってみよう

  1. greetings の隣に hello を作り、go mod init example.com/hello。
  2. hello.go に右のコードを書く（package main）。
  3. go mod edit -replace example.com/greetings=../greetings で、まだ公開していないモジュールをローカルのパスに置き換える。
  4. go mod tidy → go.mod に require が追加される。
  5. go run .。

ポイント

  • import は モジュールパス + パッケージのディレクトリ。今回はモジュール直下なので example.com/greetings。
  • replace ディレクティブは開発中の一時措置。公開後は go get して外す。
  • 擬似バージョン v0.0.0-00010101000000-000000000000 は「タグが無いローカルモジュール」の印。
$ cd .. && mkdir hello && cd hello $ go mod init example.com/hello hello/hello.gopackage main import ( "fmt" "example.com/greetings" ) func main() { message := greetings.Hello("Gladys") fmt.Println(message) } $ go mod edit -replace example.com/greetings=../greetings $ go mod tidy $ cat go.mod module example.com/hello go 1.27 replace example.com/greetings => ../greetings require example.com/greetings v0.0.0-00010101000000-000000000000 $ go run . Tutorial 2 · Part 3/7

エラーを返して処理する：多値返却と if err != nil

やってみよう

  1. greetings.go の Hello を右上のように変更：戻り値を (string, error) にし、名前が空なら errors.New でエラーを返す。
  2. hello.go を右下のように変更：2 つの戻り値を受け取り、err != nil なら log.Fatal で終了。わざと Hello("") を渡す。
  3. hello ディレクトリで go run .。
$ go run . greetings: empty name exit status 1

Go のエラー処理の流儀

  • 例外を投げない。エラーは普通の値として最後の戻り値で返し、呼び出し側が if err != nil で毎回判定する。
  • 成功時はエラーに nil を返す。
  • log.SetPrefix / log.SetFlags(0) で出力の接頭辞と、日時などの付加情報を制御。log.Fatal は表示して exit status 1。
greetings/greetings.go（抜粋。"errors" を import に追加）func Hello(name string) (string, error) { // If no name was given, return an error with a message. if name == "" { return "", errors.New("empty name") } message := fmt.Sprintf("Hi, %v. Welcome!", name) return message, nil }
hello/hello.go（抜粋。"log" を import に追加）func main() { log.SetPrefix("greetings: ") log.SetFlags(0) message, err := greetings.Hello("") if err != nil { log.Fatal(err) } fmt.Println(message) }

Tutorial 2 · Part 4/7

ランダムな挨拶を返す：スライスと math/rand

やってみよう

  1. greetings.go に math/rand を import し、非公開関数 randomFormat を追加。Hello は fmt.Sprintf(randomFormat(), name) で書式を差し替える。
  2. hello.go の呼び出しを Hello("Gladys") に戻す。
  3. go run . を 何回か実行し、挨拶が変わることを確認。

ポイント

  • スライス []string{…}：長さが可変の配列ビュー。len() で長さ。
  • rand.Intn(n) は 0 以上 n 未満の乱数。Go 1.20 以降はシード不要（自動でランダム初期化される。古い記事の rand.Seed(time.Now().UnixNano()) は不要）。
  • 小文字始まりの randomFormat はパッケージ内からしか呼べない。
greetings/greetings.go（抜粋）import ( "errors" "fmt" "math/rand" ) func Hello(name string) (string, error) { if name == "" { return name, errors.New("empty name") } // Create a message using a random format. message := fmt.Sprintf(randomFormat(), name) return message, nil } // randomFormat returns one of a set of greeting messages. func randomFormat() string { formats := []string{ "Hi, %v. Welcome!", "Great to see you, %v!", "Hail, %v! Well met!", } return formats[rand.Intn(len(formats))] } $ go run . Great to see you, Gladys! $ go run . Hail, Gladys! Well met!

Tutorial 2 · Part 5/7

複数人に挨拶する：map と for … range

やってみよう

  1. greetings.go に Hellos 関数を追加（Hello は変更しない＝既存の呼び出し元を壊さない）。
  2. hello.go で名前のスライスを作り、greetings.Hellos(names) を呼ぶ。
  3. go run .。

ポイント

  • map map[string]string：キー→値の連想配列。make で生成し、messages[name] = message で代入。
  • for _, name := range names：range はインデックスと値を返す。使わない方は _（ブランク識別子）で捨てる。
  • 途中でエラーが出たら nil, err を返して中断。
  • map の表示順は不定（fmt.Println はキーでソートして表示する）。
greetings/greetings.go（追加分）// Hellos returns a map that associates each of the named people // with a greeting message. func Hellos(names []string) (map[string]string, error) { messages := make(map[string]string) for _, name := range names { message, err := Hello(name) if err != nil { return nil, err } messages[name] = message } return messages, nil } hello/hello.go（main の中） names := []string{"Gladys", "Samantha", "Darrin"} messages, err := greetings.Hellos(names) if err != nil { log.Fatal(err) } fmt.Println(messages) $ go run . map[Darrin:Hi, Darrin. Welcome! Gladys:Great to see you, Gladys! Samantha:Hail, Samantha! Well met!]

Tutorial 2 · Part 6/7

テストを追加する：_test.go と go test

やってみよう

  1. greetings ディレクトリに greetings_test.go を作り、右のコードを書く。
  2. go test、次に go test -v。
  3. わざと壊す：Hello の message := fmt.Sprintf(randomFormat(), name) を fmt.Sprint(randomFormat()) に変えて go test。失敗を確認したら元に戻す。
$ go test PASS ok example.com/greetings 0.002s $ go test -v === RUN TestHelloName --- PASS: TestHelloName (0.00s) === RUN TestHelloEmpty --- PASS: TestHelloEmpty (0.00s) PASS ok example.com/greetings 0.002s # Hello を壊した後 $ go test --- FAIL: TestHelloName (0.00s) greetings_test.go:15: Hello("Gladys") = "Great to see you, %v!", <nil>, want match for `\bGladys\b`, nil FAIL example.com/greetings 0.002s
greetings/greetings_test.gopackage greetings import ( "regexp" "testing" ) // TestHelloName calls greetings.Hello with a name, checking // for a valid return value. func TestHelloName(t *testing.T) { name := "Gladys" want := regexp.MustCompile(`\b`+name+`\b`) msg, err := Hello("Gladys") if !want.MatchString(msg) || err != nil { t.Errorf(`Hello("Gladys") = %q, %v, want match for %#q, nil`, msg, err, want) } } // TestHelloEmpty calls greetings.Hello with an empty string, // checking for an error. func TestHelloEmpty(t *testing.T) { msg, err := Hello("") if msg != "" || err == nil { t.Errorf(`Hello("") = %q, %v, want "", error`, msg, err) } }

規約：ファイル名は *_test.go、関数は TestXxx(t *testing.T)。t.Errorf は失敗を記録して続行、t.Fatalf は即中断。テストは同じパッケージに置くので非公開関数も呼べる。

Tutorial 3 · Multi-module workspaces (1/2)

ワークスペース：複数モジュールを replace なしで同時に開発する

やってみよう

  1. ホームに workspace/hello を作り、go mod init example.com/hello。
  2. go get golang.org/x/example/hello/reverse で依存を追加し、右の hello.go を書いて go run . → olleH。
  3. workspace に戻り、go work init ./hello → go.work ができる。
  4. ワークスペースのルートから go run ./hello で実行できる。

go.work とは

  • Go 1.18 で導入。use に列挙したローカルのモジュールを、依存解決の際に main モジュール扱いにする。
  • Part 2 の replace と違い 各モジュールの go.mod を汚さない。ライブラリと利用側を同時に直すときに便利。
  • 通常 go.work はコミットしない（開発者ごとのローカル設定）。

Tutorial 3 · Multi-module workspaces (2/2)

依存先モジュールを clone してワークスペースで書き換える

やってみよう（workspace ディレクトリで）

  1. git clone https://go.googlesource.com/example（GitHub ミラー github.com/golang/example でも可）。
  2. go work use ./example/hello で go.work に追加。
  3. example/hello/reverse/int.go を新規作成し、Int 関数を追加。
  4. hello.go で reverse.Int(24601) も表示するよう変更。
  5. go run ./hello → 手元で加えた Int が、公開版ではなく clone した方から解決されて動く。

その他の go work コマンド

go work use [-r] dirモジュールを追加（-r で再帰）。存在しないものは削除
go work editgo mod edit と同様に go.work を編集

Tutorial 4 · Working with JSON (1/2)

JSON：構造体 ⇄ JSON の変換（Marshal / Unmarshal）

やってみよう

  1. json ディレクトリで go mod init example/json。
  2. 右の main.go を書いて go run .。
  3. フィールド名を小文字（name）にして再実行 → JSON に出なくなる。公開フィールドだけが対象。
  4. Name string `json:"name"` のように構造体タグを付けてキー名を変えてみる。

v1 と v2（Go 1.27 時点）

  • 公式チュートリアルは encoding/json/v2 で書かれている。Go 1.25 で実験導入、1.27 で標準の encoding/json も v2 実装ベースになり、GOEXPERIMENT 指定なしで encoding/json/v2 を import できる。
  • Marshal / Unmarshal の使い方は v1 と同じ。v2 は MarshalWrite / UnmarshalRead（io.Writer / io.Reader 直結）や、既定で大文字小文字を区別するキー照合などが違う。
  • Go 1.24 以前では "encoding/json" に読み替えれば右の例はそのまま動く（MarshalWrite を除く）。
json/main.gopackage main import ( "encoding/json/v2" // Go 1.24 以前は "encoding/json" "fmt" "time" ) type Message struct { Name string Body string Time time.Time } func main() { m := Message{"Alice", "Hello", time.Date(2011, 1, 25, 0, 0, 0, 0, time.UTC)} b, err := json.Marshal(m) // Go の値 → JSON バイト列 if err != nil { panic(err) } fmt.Println(string(b)) var m2 Message err = json.Unmarshal(b, &m2) // JSON → Go の値（ポインタを渡す） if err != nil { panic(err) } fmt.Printf("%+v\n", m2) } $ go run . {"Name":"Alice","Body":"Hello","Time":"2011-01-25T00:00:00Z"} {Name:Alice Body:Hello Time:2011-01-25 00:00:00 +0000 UTC}

Tutorial 4 · Working with JSON (2/2)

構造の分からない JSON：any と型スイッチ、ストリーム、カスタム変換

やってみよう

  1. 右のコードを main に追加して実行。JSON の数値は float64、配列は []any、オブジェクトは map[string]any になることを確認。
  2. 同じ JSON を type FamilyMember struct { Name string; Age int; Parents []string } に Unmarshal してみる（型が決まっているならこちらが普通）。
  3. json.MarshalWrite(os.Stdout, m) で標準出力に直接書き出す（v2）。

覚えておくこと

  • 変換できないもの：チャネル・関数・複素数、循環参照。map のキーは文字列（または整数）。
  • ポインタフィールドは指す先の値として出力、nil なら null。JSON に無いキーはゼロ値のまま。
  • 独自の表現にしたいときは MarshalJSONTo(*jsontext.Encoder) / UnmarshalJSONFrom(*jsontext.Decoder) を実装（v1 では MarshalJSON() ([]byte, error)）。
main に追加 raw := []byte(`{"Name":"Wednesday","Age":6,"Parents":["Gomez","Morticia"]}`) var f any if err := json.Unmarshal(raw, &f); err != nil { panic(err) } for k, v := range f.(map[string]any) { // 型アサーション switch vv := v.(type) { // 型スイッチ case string: fmt.Println(k, "is string", vv) case float64: fmt.Println(k, "is float64", vv) case []any: fmt.Println(k, "is an array:") for i, u := range vv { fmt.Println(i, u) } default: fmt.Println(k, "is of a type I don't know how to handle") } } json.MarshalWrite(os.Stdout, m) // io.Writer へ直接（"os" を import） $ go run . Name is string Wednesday Age is float64 6 Parents is an array: 0 Gomez 1 Morticia {"Name":"Alice","Body":"Hello","Time":"2011-01-25T00:00:00Z"}

症状原因と対処
declared and not used: namesGo は未使用の変数・import をコンパイルエラーにする。消すか使う。import は VS Code の Go 拡張（goimports）が保存時に自動整理する
