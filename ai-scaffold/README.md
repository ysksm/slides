# 自動実装 × AI — Rails generate を DDD フロントエンドで再現する

Rails の `generate` のようにモデル情報を入力すれば UI・モデル・ユースケース・リポジトリが揃う仕組みを、「スクリプトが決定論的に生成し、AI がその引数を考える」形で設計した検討スライド（全 32 枚・自己完結型 HTML）。GitHub Issue [#16](https://github.com/ysksm/slides/issues/16) に対応。

前提：Web フロントエンド / ドメイン駆動設計 / レイヤードアーキテクチャ + DIP / プレゼン（React・Hooks・Redux）・アプリ・ドメイン（VO と ID を厳重に、Entity 中心）・インフラ（Repository パターン）/ Repository は DI / テスト用バックエンドあり / IDL は TypeSpec。

- **検討メモ** — Rails generate が成立する理由、決定論・判断・創作の 3 ゾーン、入力の 3 起点、「AI の引数 = 生成仕様ファイル」、部分生成と再生成、決定論の担保、役割分担
- **4 案の提案と比較** — A. 生成仕様駆動の自作ジェネレーター / B. TypeSpec 単一ソース / C. 規約 + ガードレールで AI 生成 / D. 既存テンプレート CLI
- **推奨案の設計** — 案 A を軸に B のインポータと C のガードレールを吸収。全体構成、生成仕様の例、生成物ツリー、テンプレートの中身、レジストリ方式の配線、TypeSpec 接続、テスト用バックエンド、AI ワークフロー（スキル `/gen`）、CLI 仕様
- **実施計画とタスク** — 6 フェーズ、T-01〜T-53、リスクと対策、成功指標

## 閲覧方法

`index.html` をモダンブラウザで開くだけ。インストール・ビルド不要（Web フォントのみ Google Fonts を参照）。

| 操作 | キー |
|---|---|
| 次へ / 前へ | `→` `Space` `PageDown` / `←` `PageUp` |
| 最初 / 最後へ | `Home` / `End` |
| 目次 | `O` または `T` |
| 全画面 | `F` |
| 印刷 / PDF | `P` |

URL のハッシュ（`#12` など）でスライド番号を直接指定できる。スライド面のクリック（右 60% で次へ、左 40% で前へ）とスワイプにも対応。
