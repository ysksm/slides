# Redmine の UI を SPA で作る（構成・導入編）

[Issue #26](https://github.com/ysksm/slides/issues/26) の技術検討資料。UI の置き換え、別 Web サーバー経由の配信と認証、Electron・Tauri・PWA によるデスクトップアプリ化を整理します（全 19 枚、調査日: 2026-09-14）。

- [HTML スライド](index.html): 全 19 枚。ビルド不要。
- [調査メモ](research.md): 構成案、NGINX 設定例、認証・API の確認項目、公式出典。

## 閲覧・編集

`index.html` をブラウザで開きます。← → / Space で移動、Home / End で先頭・末尾、O で一覧、F で全画面、P で印刷/PDF。`#9` のようなハッシュでページを直接指定できます。スワイプにも対応します。

`playwright-overview/index.html` の 1280×720 テンプレートを利用しています。HTML 内の本文を編集できます。Web フォントが取得できない場合はシステムフォントで表示します。

## 対象と前提

既存 Redmine を活用して UI を開発する設計者・実装者向けです。API の仕様や置き換え方式の整理は [redmine-ui-spa](../redmine-ui-spa/) にあり、本デッキは構成の選択と導入手順に寄せています。稼働バージョン、認証基盤、導入プラグインは未指定のため、推奨構成は設計案です。Redmine に接続するアプリそのものや、検証済みの本番設定を提供するものではありません。

目次への登録はマージ後に目次更新 Issue で行います。
